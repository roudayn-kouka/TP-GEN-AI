# IGL5 – Practical Work (TPs)

This repository brings together the practical work (TPs) completed during the **IGL5 – Software Engineering** academic year at the Faculty of Sciences of Tunis (FST), University of Tunis El Manar, Tunisia, for the 2026–2027 academic year.

## 📚 Contents

The repository is organized by subject and practical work, covering the different topics studied throughout the IGL5 program.

### Generative AI

- **TP 1 – Generative Adversarial Networks (GANs)**
  - Basic GAN implementation with PyTorch
  - MNIST and Fashion-MNIST image generation
- **TP 2 – Types of GANs**
  - DCGAN implementation with TensorFlow
  - StyleGAN3 image generation, interpolation, and fine-tuning

More practical assignments will be added progressively throughout the academic year.

## 🎯 Purpose

The goal of this repository is to centralize IGL5 practical assignments, document implementations, and keep coursework organized in one place for learning and revision.
